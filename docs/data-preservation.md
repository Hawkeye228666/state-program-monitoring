# Сохранение существующих данных

До удаления прежнего режима выполнен однократный перенос фактической базы в PostgreSQL preserved_pg_only_0. Это сохранение существующих строк, не повторный импорт XML. Сверены все поля таблиц, количества, FK и последовательности. 6792наблюдения,6показателей,172территории,20периодов,6источников,1исторический импорт. В исходной базе нет auth-пользователей; существующие метаданные и история перенесены полностью. Проверенные прежние копии Downloads совпали по SHA256.

Резервная SQLite-копия и pg_dump находятся вне Git в work/preserved-data/. ИсходныйSHA256: d0ce2bddc9efe86195cc41c8ce42623ec09593bcb942aa0dd969cc487c75db8a; резервная копия: 7f18901e2cef1b8d77ec58df82c4947edb7080d900c10b80e35a7c5ecbda33ac. Private report.json содержит полные сверки таблиц. Тома/дампы/учётные записи в поставку не входят.

После переноса существующая PostgreSQL обновлена миграцией0003; все строки до/после сравнивались с нормализацией только представления Decimal. Значения, связи и метаданные совпали. Сохранённая БД остаётся на локальном диске; сервер после проверок остановлен.

Команда переноса и прежние сценарии удалены из актуального приложения. Новая установка читает только оригинальные SDMX. История Git не переписывалась.
