Все 20 тестов проекта повторно прошли на Python 3.14.7 с зафиксированными зависимостями. Журнал: python314_tests.txt. Ниже сохранён первоначальный отчёт проверки. Полная установка нового venv через BAT в этой дополнительной проверке не выполнялась.

Дата проверки: 25 октября 2026 года. Содержимое этого отчёта отделяет выполненные проверки от ограничений среды. Полный журнал тестов: test_results.txt. Машиночитаемые количества и ответы Django-клиента: verification.json.

- Выполнено 20 тестов, результат OK. Проверены каждый из файлов, вложенные ZIP, повторная загрузка, изменение значения, откат всего пакета, DTD/XXE, повреждения, опасные ZIP-пути, ограничения объёма/глубины, кварталы и ОКФС, несколько значений измерения, строковые коды, пропуски, десятичная точность, пустая база, оба режима выборки, сохранение фильтров, сортировка, полный CSV и данные графиков.

- Копии оригинальных DOCX/ZIP сохранены без изменения, SHA-256 приведены в verification.json. Набор производных тестовых XML не подмешивался в сдаваемую базу.

## Ограничения проверки

Браузерное средство не смогло подключиться к 127.0.0.1:8000/8001: тайм-аут. Прямой HTTP-запрос из инструментальной среды вернул EACCES, затем средство управления браузером остановило сеанс. Поэтому визуальный рендер веб-интерфейса, интерактивная работа JavaScript, адаптивность на устройствах и полный сценарий через реальный браузер не подтверждены. В презентации нет реальных скриншотов веб-приложения, это требование осталось невыполненным. В неё включены фактические данные и редактируемый график; нарисованные экраны за скриншоты не выдаются.

Для просмотра вывода шаблонов сохранены самодостаточные HTML-снимки в html_snapshots. Они сформированы настоящими Django-шаблонами из сдаваемой базы, но не являются скриншотами и не заменяют проверку браузера. Снимки статические: навигация и отправка форм предполагают работающий сервер.

В среде нет стандартного установленного Python и системного py -3.12. Работоспособность проверена на встроенном CPython 3.12.14, с отдельной установкой ровно зависимостей requirements в рабочую папку. Сценарий установки обычного Python/venv из README и run_windows.bat не удалось проверить буквально. Команды Django для миграций, импорта, тестирования и запуска реально выполнены эквивалентным интерпретатором. Окружение и инструментальные скрипты не входят в комплект.

Полные официальные PDF Правительства не удалось скачать из этой среды. Исторические факты сверены по индексированным текстам официальных публикаций и снабжены ссылками в паспортах. Жилищные этапы указаны по официальному заключению контрольного органа; их нельзя автоматически переносить на последующие редакции программы. Для научной программы показано досрочное прекращение в 2019 году. Актуальная редакция современных программ здесь не моделируется.

GitHub-репозиторий не подключён. Ветка, push и pull request не выполнялись. Файл Actions подготовлен, но облачный запуск CI не проводился.
