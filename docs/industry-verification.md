Воспроизводимый повтор на собственной проверочной PostgreSQL (после настройки окружения и загрузки старых шести файлов):

```text
python manage.py benchmark_sdmx materials/industry-source.zip --manifest manifests/industry.json --report benchmarks/industry.json --repeat
```

Команда не очищает БД: для измерения именно добавления используйте новую отдельную БД. Отчёт сохраняет версии, SHA, время распаковки, счётчики по файлам, процессный high-water RSS и время запросов. RSS относится к Python-процессу, память сервера PostgreSQL в него не входит. Исходный архив предоставляется отдельно; инструкция и SHA — connect-program.md.
