## Архитектура и запуск

Django 5.2.13, SQLite, Bootstrap и Chart.js хранятся локально. Windows: `run_windows.bat`, либо venv, pip install, migrate, import_sdmx, runserver. Контейнеров, PostgreSQL, Gunicorn и авторизации в исходном проекте нет. Все страницы, включая загрузку, доступны анонимно. Небольшой JSON-экспорт не имеет пагинации.

Ключ наблюдения: показатель + территория + Period + непустой SHA256 канонического JSON всех существенных измерений. Period.code включает квартал (`2014-Q1`), PERIOD также входит в хеш. Отсутствие ОКФС не заменяется кодом 200. Число хранится текстом ради точности SQLite, Decimal применяется при чтении.

## Существующие визуализации

Линейный график, столбчатая диаграмма, тепловая таблица. Общая select_rows для таблицы, CSV, JSON и графиков. Пропуски не заменяются нулём. Графики ограничены одним показателем и единицей, 12 рядами. Старые графики допускают явно выбранные разные уровни территорий. Нет dumbbell/scatter/boxplot и экспорта изображения.

## Обнаруженные задачи

1. Повторный импорт перезаписывает названия и метаданные справочников, включая ручные изменения.
2. Нет явной диагностики неизвестного и пропущенного ОКФС, отдельного состояния отсутствующего измерения в интерфейсе.
3. Нет контроля доступа и ролей, контейнерного запуска, средств переноса/восстановления PostgreSQL.
4. Нет новых аналитических графиков и документированного API с пагинацией.
5. Docker и psql отсутствуют в PATH, стандартные каталоги Docker/PostgreSQL не найдены. Это ограничивает локальную проверку контейнеров, но не является проверкой работоспособности Compose.

Подробный независимый аудит всех XML и найденные ограничения приведены в okfs-audit.md. Оригинальные DOCX/ZIP сохранены без изменения.
