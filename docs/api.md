# API чтения и экспорт CSV

Это интерфейсы самого учебного приложения. Они не являются API Мосстата или ЕМИСС и не подключаются автоматически к корпоративным системам. Версия: `/api/v1/`. Формат ответа: JSON UTF-8; изменения через API не поддерживаются.

## Доступ

Войдите через `/accounts/login/` под пользователем с правом `monitor.view_observation`. API использует ту же сессию Django, что и браузер. Группы «Аналитик», «Оператор загрузки» и «Администратор» создаются командой `python manage.py setup_roles`. Пользователей и пароли команда не создаёт. Администратор назначает группы через `/admin/`; для входа в этот раздел нужен `is_staff`.

Без сессии API отвечает 401 JSON, без права чтения — 403 JSON. В браузере можно открыть указанные ниже URL после входа. Внешний клиент должен пройти обычный вход Django с CSRF-токеном и сохранить session cookie. Cookie и пароль нельзя включать в исходный код, отчёты или URL. Токены доступа, OAuth и корпоративное SSO в демонстрации не реализованы.

## Показатели

`GET /api/v1/indicators/`

| Параметр | Назначение |
| --- | --- |
| `program` | `housing` или `science`; без параметра — показатели всех программ |
| `indicator` | Строковый ID из имени XML/метаданных; можно повторять |
| `page` | Номер страницы, начиная с 1 |
| `page_size` | Размер страницы от 1 до 500, по умолчанию 50 |

Пример: `/api/v1/indicators/?program=science&indicator=44198&page=1&page_size=50`.

Каждый элемент содержит ID, название, единицу, программу, методологию, организацию-источник, число наблюдений, перечень измерений и список фактически используемых файлов-источников. Источник содержит `filename`, SHA-256, `header_id`, `dataset_id`, дату подготовки и дату регистрации файла. Несколько версий XML одного показателя различаются по SHA-256.

## Наблюдения

`GET /api/v1/observations/`

Выборка использует `monitor.queries.select_rows`, общий с таблицей и CSV. Сервер не складывает значения и не подставляет нули вместо отсутствующих данных.

| Параметр | Назначение |
| --- | --- |
| `program` | `housing` или `science`; по умолчанию `housing` |
| `mode` | `one` (один показатель, по умолчанию) или `all` (вся программа) |
| `indicator` | Один ID для режима `one`; без ID выбирается первый показатель программы по file_id |
| `regions` | Строковый код территории; повторяемый параметр |
| `periods` | Точный код периода: `2014` или `2014-Q1`; повторяемый параметр |
| `level` | `country`, `district`, `subject`, `municipality`, `aggregate`, `unknown` |
| `dim_<код>` | Значение существенного дополнительного измерения; повторяемый параметр |
| `dim_s_OKFS` | Конкретный строковый код ОКФС, например `12` или `200`; также состояния `__absent__`, `__missing__`, `__unknown__` там, где фильтр ОКФС применим к выбранным показателям |
| `sort` | `territory`, `period`, `indicator`, `value`, `-value` |
| `page`, `page_size` | Те же правила пагинации, что для показателей |

Пример квартальной выборки:

```text
/api/v1/observations/?program=science&mode=one&indicator=44198&regions=643&periods=2014-Q1&periods=2014-Q2&periods=2014-Q3&dim_s_OKFS=200&sort=period
```

В исходном наборе эта выборка содержит 3 наблюдения: `111.7`, `120.3`, `125`. Годовой код `2014` не равен квартальному `2014-Q1`. Параметры `regions` и `periods` не ограничены одной записью: повторяйте их через `&`. Несколько значений одного измерения трактуются как «ИЛИ», разные фильтры — как «И». Неизвестное значение фильтра не создаёт фиктивного нулевого наблюдения.

Каждое наблюдение содержит:

- `id`, строковый `indicator` и `last_import_id`;
- `territory`: исходный строковый код, название и уровень;
- `period`: код, подпись, год и тип `year`/`quarter`;
- `value`: точная десятичная **строка** с точкой либо JSON `null`;
- `raw_value`: исходная запись числа, например `111,7`;
- единицу, все `dimensions`, исходные `dimension_labels`, атрибуты и статусы;
- `okfs`: состояние, исходный код, подпись и диагностическое сообщение;
- `source`: идентификаторы и SHA-256 конкретного исходного XML.

Строковый `value` сохраняет точность PostgreSQL Numeric. Клиент должен разбирать его через Decimal при точных вычислениях. Перевод в JavaScript Number выполняется только для отрисовки графика, не меняя исходное число в БД и экспорте.

Состояния ОКФС:

| `state` | Значение |
| --- | --- |
| `absent` | Измерение отсутствует, `code=null`; это не итог 200 |
| `missing` | Источник объявляет измерение, но не заполняет код |
| `unknown` | Исходный код сохранён, соответствие справочнику не подтверждено |
| `known` | Конкретный известный код и его исходная подпись |

Код 199 отличается от 200. В предоставленных материалах по 199 нет наблюдений, поэтому запрос этого кода возвращает пустую выборку. Список кодов в справочнике не является списком опубликованных значений.

## Пагинация и ошибки

Обёртка ответа обоих методов содержит `api_version`, `count` (полное число строк после фильтров), `page`, `page_size`, `pages`, относительные ссылки `next` и `previous` и массив `results`. Последняя/первая ссылка равна `null`. Фильтры сохраняются в ссылках перехода. Результат не зависит от текущей HTML-страницы таблицы.

| HTTP | Причина |
| --- | --- |
| 200 | Успешная выборка, включая пустую |
| 400 | Ошибка размера/номера страницы, режима, показателя или неприменимого измерения |
| 401 | Нет авторизованной сессии |
| 403 | Недостаточно прав |
| 404 | Не найдена программа |
| 405 | Метод, отличный от GET, для авторизованного читателя |

API не меняет БД. Для загрузки используйте защищённую форму `/upload/` под оператором. `/healthz/` — отдельная проверка связи приложения с БД, а не аналитический API.

## CSV

В интерфейсе выберите фильтры и нажмите экспорт либо откройте:

```text
/explore/?program=science&mode=one&indicator=44198&regions=643&periods=2014-Q1&dim_s_OKFS=200&format=csv
```

Файл `monitoring.csv` содержит **всю отфильтрованную выборку**, а не только 50 строк текущей страницы. Кодировка UTF-8 с BOM, разделитель `;`, кавычки по правилам CSV. При открытии в Excel импортируйте коды территорий и классификаторов как текст.

Первые 16 столбцов сохраняют прежний порядок: программа, ID и название показателя, код и название территории, уровень, период, исходное и десятичное значения, единица, множитель, измерения, статус, Header/ID, DataSetID и SHA-256. В конец добавлены столбцы состояния ОКФС, кода, подписи и диагностики. Коды территорий защищены начальным апострофом от потери ведущих нулей. Значения, начинающиеся с символов формулы, защищены от выполнения в табличном редакторе. Поэтому CSV является отчётным экспортом, а для машинного получения точных исходных строк предпочтителен API.

Экспорт и API доступны только читателям. Загружаемые файлы не выдаются открыто по произвольному пути; метаданные позволяют определить исходник и проверить его хеш.

## Ограничения интерфейса

Это небольшой API для пилота на 6 792 наблюдениях. Пагинация ограничивает размер ответа, но единый механизм выборки пока загружает отфильтрованные наблюдения в память. Для большого массива потребуются профилирование, серверная пагинация/потоковый CSV и согласованные лимиты запросов. Контракт корпоративной интеграции, обезличивание, отдельные технические учётные записи, SSO, долговременная политика версий и SLA согласуются при пилоте. Наличие нашего API не означает наличие аналогичного интерфейса у Мосстата или ЕМИСС.
