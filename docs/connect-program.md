# Подключение программы и показателя

## Оператор через сайт

1. Администратор назначает группу «Оператор загрузки». Она включает просмотр, загрузку, создание и изменение программы; доступ к Django Admin этим не предоставляется.
2. «Новая программа»: название, уникальный ASCII slug, описание, подтверждённые сроки и ссылки HTTP/HTTPS. Неизвестные сведения оставьте пустыми. Сохранение возвращает к загрузке; при создании из предпросмотра — к той же фоновой задаче.
3. На странице «Загрузка» используйте верхнюю форму фонового импорта. Выберите ZIP/SDMX/XML и существующую программу, либо назначьте её после проверки. Для данных ЕМИСС с s_OKATO действует структурный профиль; неоднозначные поля требуют заранее подтверждённого MappingProfile.
4. Worker проверяет файлы на диске, публикует только ограниченные примеры, числа и метаданные. Задача доступна по ссылке и в истории. Закрывать браузер можно. Сессия содержит только небольшие идентификаторы, не наблюдения.
5. Подтвердите привязку каждого ID и профиль полей. Все годовые XML одного Indicator/@id пополняют один Indicator. При попытке назначить уже существующий ID другой программе импорт отклоняется; изменение принадлежности выполняется отдельно через метаданные администратора.
6. После подтверждения задача попадает в очередь. Статусы: preview_pending → preview_running → awaiting_approval → queued → importing → success/error. Ошибка публикации откатывает данные всей загрузки. Для исправленных файлов создайте новую задачу; повтор неизменных данных не создаёт строки повторно.

Worker запускается автоматически обновлённым run_windows.bat (`app worker`). При ручном запуске: `docker compose up --build -d --wait app worker`. Журнал: `docker compose logs -f worker`. После сбоя процесса PostgreSQL откатывает незавершённую транзакцию; следующий единственный worker возвращает прерванную задачу в очередь. Одновременные worker блокируются advisory lock. CLI-импорт и worker сериализуют публикацию; UUID чужой задачи не даёт оператору права её подтвердить.

## Воспроизводимый CLI для предоставленного архива

Оригинал «Материал для задания 3 доп.zip» предоставляется отдельно. Он не изменён и не входит в Git/образ/ZIP проекта. Локальный источник задания: `C:\Users\Genus\Downloads\Материал для задания 3 доп.zip`. Скопируйте его в `materials/industry-source.zip` (этот путь игнорируется Git/Docker).

SHA256: `a7d73a00fa202de721f9515dd163474621c796a56de40deeff1faedc2f6ce49c`. Сжатый размер 46 222 620 байт. Проверка PowerShell:

```powershell
Get-FileHash materials/industry-source.zip -Algorithm SHA256
```

Сначала запустите run_windows.bat. Затем из корня проекта:

```powershell
docker compose run --rm --no-deps -v "${PWD}/materials/industry-source.zip:/input/source.zip:ro" app python manage.py import_sdmx /input/source.zip --manifest manifests/industry.json
```

Linux использует ту же команду с `${PWD}`. Для собственного ID: `--program <slug>` вместо `--manifest`; программа должна существовать. `--profile <id>` применяет подтверждённый MappingProfile. Команда печатает прогресс и итоговый ImportRun. Многочасовой HTTP-запрос не используется. Не запускайте резервное копирование одновременно с самостоятельным CLI-импортом; worker backup останавливает и восстанавливает автоматически.

Manifest создаёт «Развитие промышленности и повышение ее конкурентоспособности», назначает 43007/58699/43578/43909 и документирует связь 43007→58699 без склейки. Официальные сроки и паспорт не выдуманы. Связь доступна в RelatedSeries в админке.

## Сопоставление и ограничения

Поддерживается предоставленный ЕМИСС GenericData SDMX 1.0 с Header, Description/Indicator, встроенными CodeLists и DataSet/Series/SeriesKey/Obs. Это не универсальный SDMX-процессор для всех версий и структур. Территория по умолчанию s_OKATO; s_OKSM — независимый разрез. Time и PERIOD определяют полное временное окно. EI, UNIT_MULT, DECIMALS/FREQ сохраняются в ключевых атрибутах; статусы/примечания — изменяемый payload.

MappingProfile — JSON `{field: {role, codelist, transform}}`. Роли ограничены territory/dimension/unit/multiplier/period/attribute/status; transform допускает только identity. Профиль должен покрывать все SeriesKey и указывать одну территорию. При наличии s_OKATO она не подменяется s_OKSM. Произвольный Python, SQL, eval или шаблоны в профилях не исполняются. Подтверждённые профили сохраняются и выбираются в загрузчике; подготовить нестандартный профиль может администратор.

Основной импорт потоковый. Режим нижней формы и CLI без назначения оставлен для небольших старых файлов с прежними пределами 20/15/80 МБ; новые и большие файлы следует подавать в верхнюю форму или CLI с manifest/program. Старый ограниченный интерфейс не заявляется способом обработки промышленного архива.

Пределы настраиваются SDMX_MAX_UPLOAD (128 МиБ), SDMX_MAX_XML (512 МиБ), SDMX_MAX_EXPANDED (8 ГиБ, включает вложенные ZIP и XML), SDMX_MAX_XML_DEPTH (64), SDMX_MAX_SERIES_OBS (4096); предел вложенных архивов 3, элементов 256. ZIP пути, шифрование, symlink, DTD/сущности отклоняются. Потребление памяти зависит от одного ограниченного Series, справочников и SQL-пакета, не от числа наблюдений. Диск должен вмещать исходные XML, staging/сортировки и основную PostgreSQL с индексами; для полного архива предусмотрите десятки ГиБ свободного места. Частичные временные файлы удаляются; content-addressed XML после отката могут остаться как непубликованные источники вне БД.

PostgreSQL COPY пишет во временный staging; проверка полного ключа отделяет одинаковые и конфликтующие дубликаты. Последние отменяют весь импорт. Публикация INSERT/ON CONFLICT выполняется в той же транзакции; reader видит прежнюю либо полностью новую версию. История ошибки сохраняется отдельно. Счётчики raw/unique/added/updated/skipped/rejected и исходные дубликаты не смешиваются.

Таблица/API используют SQL-фильтры и SQL-пагинацию. CSV выдаётся потоком, включая контекст классификаторов и полные периоды. GIN(jsonb_path_ops) поддерживает одновременные фильтры разрезов; B-tree — показатель/территорию/период. Графики используют ту же выборку только до SDMX_MAX_CHART_POINTS (5000); превышение даёт явное пояснение, таблица и полный CSV доступны. legacy format=json также ограничен; для больших выборок используйте страничный API. Значения не обрезаются молча.
