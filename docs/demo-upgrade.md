# Демонстрация доработанного модуля

Этот сценарий предназначен для обычного локального запуска. Серверная последовательность проверена тестовым клиентом с CSRF; реальная браузерная последовательность в среде Codex не выполнена (см. verification-upgrade.md).

1. Запустите run_windows.bat или Compose по README. Создайте первого администратора интерактивно, не используйте пароли из примеров тестов. Через /admin/ назначьте отдельным пользователям группы «Оператор загрузки» и «Аналитик».
2. Войдите оператором через /accounts/login/. Откройте /upload/, выберите неизменённый архив из materials/, выполните предпросмотр и подтвердите шесть файлов. При повторе исходного архива ожидается0добавленных,0обновлённых,6792пропущенных, если значения базы не изменялись. История показывает оператора и диагностику.
3. В научной программе выберите44198, территорию643, ОКФС200 и кварталы2014-Q1,Q2,Q3. Таблица и CSV должны дать111.7,120.3,125. 199непоявляется как нулевая категория. Сравнение Q1→Q3 показывает+13.3п.п.
4. Для новых графиков жилищной программы выберите43537, уровень«Субъект РФ», пять субъектов с данными2012и2020. Два периода=2012→2020; boxplot=2020. Графики перечисляют исключённые территории и не используют страну/округа в общей совокупности.
5. Для scatter выберите«Все показатели программы», год2014, один уровень«Субъект РФ», X=43512,Y=43537. Точка=регион с обеими величинами и согласованными измерениями, единицы осей разные и подписаны. Связь не доказывает причинность.
6. Нажмите «Скачать PNG», проверьте подписи и видимость данных в обычном браузере. Этот шаг ещё требует ручной приёмки. Скачать CSV можно для всей отфильтрованной выборки независимо от страницы таблицы.
7. Откройте /api/v1/indicators/ и /api/v1/observations/?program=science&indicator=44198&dim_s_OKFS=200&regions=643&periods=2014-Q1. API возвращает точные значения строками и источник с SHA256; попробуйте page_size=1.
8. Выйдите и войдите аналитиком: чтение/графики/API разрешены, прямой POST/GET загрузки отклонён403. Анонимное API возвращает401.

HTML-снимки в deliverables/html-evidence/ — реальные ответы Django с локальными ресурсами и удалёнными CSRF-токенами, а не скриншоты. Их можно открыть вручную, чтобы посмотреть отрисовку клиентских графиков без серверных действий. Они не заменяют приёмку работающего браузерного сценария.
