# Мониторинг реализации государственных программ

Работающий локальный учебный проект по заданию № 3. Django 5.2, SQLite, шаблоны, локальные Bootstrap 5.3.3 и Chart.js 4.4.8. Интерфейс и сообщения на русском языке. В комплекте готовая база с 6 792 наблюдениями из всех шести предоставленных XML, оригиналы материалов, миграции, загрузчик и тесты.

## Состав комплекта

- `manage.py`, `config/`, `monitor/` — исходный код и миграции.
- `db.sqlite3` — заполненная база (не удаляйте без резервной копии).
- `materials/` — неизменённые исходные DOCX и ZIP.
- `data/sources/` — точные копии шести XML, имена по SHA-256.
- `docs/data_research.md` и `.json` — полное исследование всех файлов.
- `docs/architecture.md` — структура, схема БД, ограничения парсера.
- `docs/validation.md` и `docs/test_results.txt` — выполненные проверки и ограничения среды.
- `docs/demo.md` — сценарий защиты на 3–5 минут.
- `presentation/project.pptx` — презентация на 10 слайдов.

## Установка на Windows

Поддерживаются CPython 3.12, 3.13 и 3.14, 64 bit. Необходим обычный дистрибутив Python с модулями venv и pip. Команды выполняются в PowerShell из корневой папки проекта, где расположен `manage.py`. В скачанном ранее комплекте эта папка называется `deliverables`.

```powershell
py -3.14 --version
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_programs
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

Откройте http://127.0.0.1:8000/ в обычном браузере. Активация окружения и изменение ExecutionPolicy не нужны. Остановить сервер: Ctrl+C. Для удобства есть `run_windows.bat`, выполняющий эти же шаги. Скрипт автоматически находит Python 3.14, 3.13 или 3.12, в том числе стандартную установку без регистрации в py Launcher. Для ручных команд можно заменить -3.14 на вашу версию. Первый запуск установки зависимостей требует интернета. Сам сайт после установки работает без CDN, Docker и платных сервисов.

Готовая база уже содержит данные. Команда повторного импорта безопасна:

```powershell
.\.venv\Scripts\python.exe manage.py import_sdmx "materials\Материал для задания 3.zip"
```

Ожидается: добавлено 0, обновлено 0, пропущено 6792, ошибок 0. Допустимы несколько путей к ZIP, SDMX и XML.

## Создание новой базы без удаления готовой

```powershell
$env:MONITOR_DB = Join-Path (Get-Location) "recreated.sqlite3"
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_programs
.\.venv\Scripts\python.exe manage.py import_sdmx "materials\Материал для задания 3.zip"
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

Получится отдельная новая база с 6792 наблюдениями. Вернуться к поставляемой базе:

```powershell
Remove-Item Env:MONITOR_DB
```

Это удаляет только переменную среды текущего PowerShell, а не файл базы.

## Проверки

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
.\.venv\Scripts\python.exe manage.py test monitor --verbosity 2
.\.venv\Scripts\python.exe manage.py inspect_sdmx "materials\Материал для задания 3.zip" --output docs
```

Тесты создают отдельную тестовую SQLite-базу и временную папку данных, не меняют сдаваемую базу. Содержательная сверка независимо читает исходные XML стандартным ElementTree и сравнивает все 6792 исходных значения и ключа с импортированной базой. Другие тесты проверяют повторный импорт, обновления, откат транзакции, повреждённый XML, DTD/XXE, ZIP-пути, лимиты, кварталы, ОКФС, пропуски, точность, режимы выборки, CSV и графики.

Файл `.github/workflows/checks.yml` запускает основные проверки на Windows при push и pull request. Репозиторий: [Hawkeye228666/state-program-monitoring](https://github.com/Hawkeye228666/state-program-monitoring). Полный проект загружен в ветку `feature/program-monitoring`, открыта [заявка на включение изменений № 1](https://github.com/Hawkeye228666/state-program-monitoring/pull/1). Слияние в main не выполнялось. Статус облачных проверок отображается во вкладке Checks. Не добавляйте `.venv`, кеши и временные папки.

## Работа с сайтом

1. На главной выберите паспорт программы и изучите исторический контекст, источники и показатели.
2. В разделе «Данные и графики» выберите одну программу. Режим «Один показатель» позволяет выбрать показатель, регионы, периоды и дополнительные измерения. Режим «Все показатели программы» возвращает три показателя выбранной программы.
3. Пустой выбор регионов или периодов означает все доступные значения. По умолчанию начальный экран показывает Российскую Федерацию. Кнопка «Сбросить всё» снимает ограничения. Есть поиск территорий, фильтр уровня, сортировка и пагинация по 50 строк.
4. Все выбранные фильтры остаются в URL. «Сохранить фильтры» запоминает выбор в сессии браузера отдельно для программы, «Восстановить» возвращает его. Для нескольких значений списка измерений используйте Ctrl.
5. CSV содержит всю выборку, а не одну страницу. Кодировка UTF-8 с BOM и разделитель `;` подходят Excel с русской локалью. Коды территорий предварены апострофом для сохранения ведущих нулей. При программном чтении CSV снимите этот защитный апостроф. Потенциальные формулы также защищены апострофом.
6. Для графиков выберите один показатель и до 12 рядов. Ряд — территория и комбинация измерений. Период сравнения столбцов выбирается из текущей выборки. Тепловая карта требует одно наблюдение на территорию и период; для 44198 выберите одну форму собственности. При неоднозначности приложение объясняет, какие фильтры уточнить.
7. Раздел «Загрузка» принимает общий ZIP, несколько вложенных ZIP либо XML/SDMX. Предпросмотр ничего не импортирует. Проверьте назначенную программу для каждого показателя, затем подтвердите. Назначение относится ко всему показателю, включая прежние наблюдения. Результат появляется в истории.

Паспорт каждого показателя содержит наименование, методику, фактические периоды, число территорий, организацию и форму при наличии, значимые измерения и исходные идентификаторы. В 43587 форма 2-наука указана внутри текста методики, хотя узел Forms отсутствует. Данные загружены из предоставленных файлов, а не получены через действующий API ЕМИСС.

## Важные ограничения

Это локальное приложение для доверенного пользователя. Нет регистрации и разграничения доступа. Сервер разработки слушает только loopback. Не публикуйте его в интернете без настройки полноценного сервера, аутентификации, HTTPS, секретного ключа и отключения DEBUG. Не используйте демонстрационный SECRET_KEY в production.

Поддержан конкретный вариант GenericData SDMX 1.0 ЕМИСС. Другие версии SDMX, CSV на входе, месячные периоды и произвольные структуры не заявлены. XML очищается от внешних сущностей через defusedxml, DTD запрещён. Лимиты и семантика ключа описаны в архитектуре.

Графики используют JavaScript Number для отображения; точные числа сохраняются как десятичный текст в базе и CSV. У программы нет подтверждённых плановых значений: приложение показывает фактическую динамику и не вычисляет процент выполнения. Классификация уровней территорий относится к предоставленному набору, полного версионного справочника и исторических границ в данных нет.

Фактические ограничения проверки среды и скриншотов перечислены в `docs/validation.md`. Все 20 тестов прошли на CPython 3.12.14 и установленном CPython 3.14.7. Исправленный BAT успешно находит Python 3.14.7; полный сценарий создания нового venv через BAT отдельно не проверялся.
