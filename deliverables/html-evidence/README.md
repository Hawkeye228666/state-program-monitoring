# Реальные HTML-ответы приложения

Ответы Django на фактически загруженных данных; CSS/JavaScript встроены, CSRF-токены удалены. Их можно открыть в обычном локальном браузере. Это статические ответы: серверные формы/переходы требуют обычного запуска. Canvas-графики и PNG-кнопки являются кодом настоящего приложения.

Эти файлы не являются скриншотами. В среде Codex отрисовка в браузере и фактическое скачивание PNG не были проверены: localhost недоступен из изолированного браузера, управление Chrome остановлено Computer Use из-за невозможности надёжно определить URL. Числовые наборы/расчёты проверены тестами отдельно.

home.html — обзор, quarters.html — РФ44198/200 2014Q1→Q3, distribution.html — пять субъектов43537 2012→2020 и boxplot2020, scatter.html — пять субъектов43512/43537 2014. Исходные URL и коды субъектов сохранены в manifest.json.
